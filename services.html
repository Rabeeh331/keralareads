What the app offers

Everything you need to manage a small shared library.

Explore the features implemented in KeralaReads for this PWA mini project.

01
📚

Smart Book Management

Add book title, author, ISBN and genre. Your collection appears instantly on the home page.

  • Add books
  • Delete books
  • View complete details
02
👤

Borrower Tracking

Borrow a book by entering a borrower name. The app assigns a 14-day due date and supports returning the book.

  • Borrower name
  • Automatic due date
  • Return confirmation
03
🔎

Search & Filters

Find books quickly using the search box or filter the collection by availability status.

  • Title/author search
  • Available filter
  • Borrowed filter
  • Overdue filter
04
📊

Library Statistics

See total, available, borrowed and overdue counts at the top of the home page.

  • Live counters
  • Status overview
  • Dynamic updates
05
📴

Offline Storage

Firebase keeps the shared library data online while the service worker caches the application shell for a fast PWA experience.

  • Local data storage
  • Offline launch
  • Persistent records
06
📱

PWA Installation

The web app can be installed on supported phones and desktops for an app-like experience.

  • Web manifest
  • Standalone display
  • Install prompt

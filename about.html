About the project

Preserving the joy of reading, one book at a time.

KeralaReads is a themed Progressive Web App created to make shared library management simple, responsive and accessible.

Purpose

Why KeralaReads?

Students and book lovers often keep book details in notebooks, spreadsheets or scattered apps. KeralaReads brings those details together in a clean interface where books can be added, searched, borrowed and returned.

The application follows the PWA approach, so the user can install it and keep using the library when there is no internet connection.

📴

Offline First

The service worker caches the application shell, while Firebase Firestore stores the shared book collection so the same library can be viewed across devices.

⚡

Interactive

Forms, search, filters and borrow/return actions make the home page dynamic and engaging.

📱

Responsive

The layout adapts to mobile, tablet and desktop screens for a consistent experience.

🔒

Private

Book records are stored in the shared Firebase library so authorized changes can be viewed from the public website.
